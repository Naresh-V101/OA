---

## 📋 Project Overview

A full-stack, modular smart health assessment application that:
- Connects to an **ESP32 DevKit V1** sensor system via **Bluetooth Low Energy (BLE)**
- Collects real-time readings from **MPU6050**, **Flex Sensor**, **FSR**, and **Vibration Sensor**
- Processes sensor data and computes movement features
- Estimates **preliminary OA risk** (Low / Moderate / High) using a **Random Forest Classifier**
- Presents results in a modern **JavaFX dashboard**
- Stores all data in **MySQL** via a **Spring Boot REST API**
- Generates **PDF reports**

## 1️⃣ Database Setup

```sql
-- 1. Open MySQL client
mysql -u root -p

-- 2. Run the schema
source path/to/smart-knee-oa/database/schema.sql
```

This creates the `smart_knee_oa` database with all tables and a default admin user.

**Default admin credentials** (for testing only – change in production):
- Email: `admin@smartkneeoa.local`
- Password: `Admin@123`

---

## 2️⃣ Python ML Service

```bash
cd smart-knee-oa/ml-service-python

# Create virtual environment
python -m venv venv
venv\Scripts\activate           # Windows
# source venv/bin/activate       # macOS/Linux

# Install dependencies
pip install -r requirements.txt

# Train the model (generates synthetic data + saves rf_model.pkl)
python train_model.py

# Start the FastAPI server
uvicorn main:app --host 0.0.0.0 --port 8000 --reload
```

Verify at: http://localhost:8000/docs  
Health check: http://localhost:8000/health

**Run tests:**
```bash
pytest tests/ -v
```

## 3️⃣ Spring Boot Backend

### Configuration

Edit `backend-springboot/src/main/resources/application.properties` or set environment variables:

| Variable         | Default                   | Description              |
|-----------------|---------------------------|--------------------------|
| `DB_USERNAME`    | `root`                    | MySQL username           |
| `DB_PASSWORD`    | *(empty)*                 | MySQL password           |
| `JWT_SECRET`     | *(dev secret)*            | JWT signing key          |
| `ML_SERVICE_URL` | `http://localhost:8000`   | Python ML service URL    |

```bash
cd smart-knee-oa/backend-springboot

# Set environment variables (Windows PowerShell)
$env:DB_PASSWORD = "your_mysql_password"

# Build and run
mvn spring-boot:run

# Or build JAR
mvn clean package
java -jar target/backend-springboot-1.0.0-SNAPSHOT.jar
```

API runs at: http://localhost:8080  
**Run tests** (uses H2 in-memory, no MySQL required):
```bash
mvn test
```

## 4️⃣ JavaFX Frontend

```bash
cd smart-knee-oa/frontend-javafx

# Run
mvn javafx:run

mvn javafx:run -Djavafx.args="-Dapi.url=http://localhost:8080"
```

**First run:**
1. The Login screen opens.
2. Register a new user account **or** use the seed admin.
3. Navigate to **Settings** to verify API/ML service URLs.
4. Toggle **Simulation Mode** on (enabled by default) to demo without hardware.
5. Start a **New Assessment**.

## 5️⃣ ESP32 Firmware

### Arduino IDE Setup

1. Install **ESP32 board support** in Arduino IDE:
   - File → Preferences → Additional Boards Manager URLs:
     `https://raw.githubusercontent.com/espressif/arduino-esp32/gh-pages/package_esp32_index.json`
   - Tools → Board → Boards Manager → Search "esp32" → Install

2. Install Libraries (Sketch → Include Library → Manage Libraries):
   - **MPU6050** by Electronic Cats

3. Open `esp32-firmware/smart_knee_oa_firmware.ino`

4. Select: **Tools → Board → ESP32 Dev Module**

5. Connect ESP32 via USB, select the correct COM port, and Upload.

### Wiring Diagram

```
ESP32 GPIO 21 (SDA) ──── MPU6050 SDA
ESP32 GPIO 22 (SCL) ──── MPU6050 SCL
ESP32 3.3V ──────────── MPU6050 VCC
ESP32 GND ───────────── MPU6050 GND

ESP32 GPIO 34 ──┬──── Flex Sensor
                └──── 10kΩ to GND
ESP32 3.3V ─────┴──── Flex Sensor other end

ESP32 GPIO 35 ──┬──── FSR
                └──── 10kΩ to GND
ESP32 3.3V ─────┴──── FSR other end

ESP32 GPIO 32 ──── Vibration Sensor DO
ESP32 3.3V ─────── Vibration Sensor VCC
ESP32 GND ──────── Vibration Sensor GND
```

**BLE UUIDs** (must match frontend):
- Service:    `4FAFC201-1FB5-459E-8FCC-C5C9C331914B`
- Characteristic: `BEB5483E-36E1-4688-B7F5-EA07361B26A8`

## 🔒 Security Notes

- Passwords are hashed with **BCrypt (cost 12)**
- JWT tokens expire after **24 hours** (configurable)
- All database queries use **JPA parameterised queries** (SQL injection safe)
- Users can only access **their own** assessment records
- JWT secret must be replaced with a strong random value in production
- **Never commit** real credentials or production JWT secrets to source control
